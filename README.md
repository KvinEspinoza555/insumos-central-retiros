# Insumos Central Retiros — DEMOSTRACIÓN PUBLICA

Aplicación web progresiva (PWA) con datos FICTICIOS. No usar datos del trabajo, ni usuarios, ni contraseñas reales. Cada equipo guarda datos solamente en su navegador y los pedidos NO se sincronizan entre equipos.

## Subir a GitHub

1. Descarga el ZIP de preparación y descomprímelo.
2. Abre https://github.com/KvinEspinoza555/insumos-central-retiros
3. Elige **uploading an existing file** o **Add file → Upload files**.
4. Sube todos los archivos de esta carpeta: index.html, styles.css, app.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png y README.md. (No subas el ZIP tal cual).
5. Pulsa **Commit changes**.
6. Después podemos crear un servicio **Static Site** en Render, con Build command `echo listo` y Publish Directory `./`. Debe mantenerse en la opción GRATUITA.
